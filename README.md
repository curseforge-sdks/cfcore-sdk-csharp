# cfcore-sdk-csharp
CFCore SDK for C#/Unity

Please download the latest [Release](https://github.com/curseforge-sdks/cfcore-sdk-csharp/releases) binaries and review their
respective README.md for more information.

## Getting Started on Unity

- Unzip cfcore-unity-x.y.z.zip into your project's Assets folder and then review  the [Unity SDK docs](/docs/cfcore-csharp-unity)
- Unzip the cfcore-unity-ui-x.y.z.zip into your project's Assets folder then review the [Unity UI docs](/docs/cfcore-unity-ui)
